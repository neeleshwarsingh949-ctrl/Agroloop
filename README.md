# Agroloop

AgroLoop is a multilingual agricultural waste marketplace that connects farmers, transporters, and recyclers to convert stubble into value.

## Live app

https://agroloop-74273.web.app

## Development

```bash
npm install
npm run dev
```

Create `.env` from `.env.example` with the Firebase Web app configuration before running locally.

## Deployment

```bash
npm run build
npm run deploy
```

Firebase Hosting, Firebase Authentication, and Realtime Database rules are configured in this repository. See [DEPLOYMENT.md](DEPLOYMENT.md) for setup details.
